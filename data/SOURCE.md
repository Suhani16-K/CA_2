# Dataset source

Name: Student Performance (Multiple Linear Regression)

Kaggle: https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression

CSV: `Student_Performance.csv`, supplied by the user from their Kaggle download. The original bytes are included without modification. 10,000 rows, five input features and the target `Performance Index`. Dataset hash is stored with the model.

Input columns: Hours Studied, Previous Scores, Extracurricular Activities (Yes/No), Sleep Hours, Sample Question Papers Practiced.

Target: Performance Index. This is an educational regression case study; results on this dataset do not establish validity for evaluating real students. Consult the Kaggle source for provenance and reuse terms.
